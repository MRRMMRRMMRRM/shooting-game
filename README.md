# 🎮 SHOOTING360

**ブラウザで即プレイできる全方位2Dシューティングゲーム**

👉 **[今すぐプレイする](https://mrrmmrrmmrrm.github.io/shooting-game/)**

---

## 📖 ストーリー

宇宙からの侵略者が地球に迫っている。

あなたは戦車を操り、押し寄せる宇宙モンスターを撃ち落とせ。
しかし撃ちすぎに注意。弾丸が外れると、森の木々を燃やしてしまう。

**地球を守るのか、環境を犠牲にするのか。それはあなたの腕次第だ。**

---

## 🕹️ 操作方法

| 操作 | 内容 |
|------|------|
| `W` `A` `S` `D` / 矢印キー | 戦車を移動 |
| マウス | 砲塔の照準を合わせる |
| クリック | ビームを発射 |

- 車体は移動方向を向き、砲塔はマウスの方向を向く

---

## 🎯 ゲームルール

- 画面内の**宇宙モンスターを全滅**させるとステージクリア
- モンスターに**触れる**とゲームオーバー
- モンスターが**画面外に逃げる**と、その数の**2倍**になって戻ってくる！
- **木にビームが当たる**と炎上する（環境破壊）

---

## 🌍 ステージ構成

| ステージ | 特徴 |
|----------|------|
| 1〜5 | 基本ステージ。通常モンスター（青）が登場 |
| 6〜10 | 強敵（紫・HP3）が登場。壁の木も減り、より難しく |
| **BOSS** | 全10ステージ制覇後にラスボス出現！ |

### ステージの壁（木）について
レベルが上がるほど外周の木が減り、モンスターが画面外に逃げやすくなる。
木を盾として使う戦略も重要。

---

## 👾 敵キャラクター

| 種類 | 色 | HP | 特徴 |
|------|----|----|------|
| 通常モンスター | 🔵 青 | 1 | 標準的な動き |
| 強敵モンスター | 🟣 紫 → 🔴 赤 → 🟡 黄 | 3 | HPで色が変化 |
| **ラスボス** | 深紅 / 炎色 | **100** | 2フェーズで挙動が変わる |

### ラスボス仕様
- HP100〜51（フェーズ1）：ダメージを受けるとHP5減るたびにモンスターを放出
- HP50〜1（フェーズ2）：一気に高速モンスターを複数放出。移動速度も上昇
- ラスボスを倒せば、残った雑魚モンスターも連鎖消滅！
